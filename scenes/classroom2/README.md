# Classroom 2

![Classroom 2 rendered in RTVK](source/classroom2.png)

Christophe Seux's Classroom demo, exported from Blender to glTF. This is a different scene from the [Japanese classroom](../classroom/).

The scene is supplied as [classroom2.glb](gltf/classroom2.glb), with its textures and camera embedded in one file.
